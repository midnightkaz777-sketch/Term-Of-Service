3. Permissions

Server administrators are responsible for configuring DevKaz Bot's permissions correctly.

Administrators should make sure the bot has the permissions required for the features they enable.

DevKaz Bot may automatically perform security or moderation actions when configured to do so by a server administrator.

Server administrators are responsible for configuring these systems appropriately for their server.
